# 官方招聘观察模块

企业从 AIMAN 公开目录取得，官网来自对应企业资料。记录官网 → 招聘入口/ATS 的来源链、网页摘要哈希和时间；只保存岗位元数据、原始申请链接，不保存职位全文。不创建或覆盖 AIMAN 的企业事实。

## 来源和覆盖

- 自动识别 Greenhouse、Lever、Ashby、Workday、飞书招聘及 Moka 公开招聘页；HTML 支持 JSON-LD，以及已核验的宇树、Weave、RoboParty、光轮、星炽、Vision One、卓益得职位列表；其它 HTML 须分别适配，普通链接不作岗位推断。
- 招聘菜单会再查一层，最多十个候选；不会因为第一个是企业文化页而跳过真正的岗位入口。忽略空锚点与 Framer 模板复制链接；识别 Next.js 预加载的 ATS 地址。
- 仅对实际在官网渲染页核验过的 ATS 使用 `seeds.ts` 中的明确租户映射；保留来源页和核验时间，不按企业名称猜 tenant。
- Workday 正常分页后续 `total=0` 表示总数只在首屏返回。以首屏总数、无重复的完整分页共同确认快照完整；正数总数变化或缺页一律失败。
- 自定义 HTML 不声明完整；职位没有再出现并不证明已关闭。完整 ATS 快照缺失才标待确认；抓取失败不刷新 `last_seen` 或关闭岗位。
- 目录企业数、已检查来源数、已成功采集数分别表达。缺官网、没有找到入口、访问失败、尚待适配、成功采集不能互相代替；未知不等于零招聘。

## Mac 浏览器采集

飞书招聘（含逐际动力、Kinetix 已核验的自定义域名）的公开页面使用正常浏览器加载与“下一页”，读取页面本身的公开职位响应。不逆向签名、不复制登录会话、不提交应聘资料。新建独立浏览器上下文，限制目标企业 ATS 和静态资源域名，屏蔽图片、音视频和字体。Mac 设置 `RECRUITMENT_BROWSER_ENABLED=true`，安装开发依赖和 Playwright Chromium；生产引擎默认关闭，无浏览器时明确报告未启用。

业务采集与浏览器均留在 Mac；VPS 只转发导出和执行受控 writer。`scripts/install-local.py` 的本地运行配置打开此公开招聘浏览器，模型及消息推送继续关闭。定时入口仍是 `scripts/run.ts`，每小时发现和采集各最多二十家，单来源采集间隔至少十二小时；发现失败每天重查，正常来源每七天重查。

Moka 同样只通过正常浏览器导航和“下一页”读取公开职位卡，不解码其接口的混淆数据、不登录、不提交申请。保留 #/job/职位编号作为岗位链接身份，避免合并为一个招聘入口；侧栏推荐不作为独立列表项。Moka 和自定义 HTML 均不声明完整快照，不能据缺席自动关闭岗位。

## 地点与时效

原始地点保留，优先用来源地址的国家、省州和城市；多地点保留多个，未知不按总部补全。省州名称统一表示同一地区。原文发布时间与首次发现分开；缺发布时间不猜测，首次导入标为存量。公开总数只包括七天内实际观察到且未过期/缺失的岗位，导入保留实际观察时间。

## 验证和未接通来源

类型检查、数据库测试、独立测试及 Web 测试沿仓库已有入口执行。`tests/feishu.browser.ts` 是显式 Mac 浏览器夹具，运行 `node --import ./tests/standalone.ts --test modules/recruitment/tests/feishu.browser.ts`；仅访问本机测试页面。真实网站核验与夹具分开记录，不能把测试页算作采集成果。

北森/智业、智联旗下招聘站及其它动态招聘页仍需分别适配；营销主页出现 HTTP 403/429、错误跳转或官网缺失时保留错误与入口，不能把失败网页解析成空岗位。企业官网缺失还需由企业资料建设补齐；目录资料更新后本模块会重新发现。
